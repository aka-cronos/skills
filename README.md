# skills

[![skills.sh](https://skills.sh/b/aka-cronos/skills)](https://skills.sh/aka-cronos/skills)

Personal [Claude Code](https://claude.com/claude-code) / Cursor skills by [aka-cronos](https://github.com/aka-cronos), distributed via the [`skills` CLI](https://github.com/vercel-labs/skills).

## Install

```bash
npx skills@latest add aka-cronos/skills
```

## Skills

- **commit-workflow** — commits staged changes as atomic Conventional Commits, one commit per concern.
- **create-pull-request** — opens a pull request against main, transplanting commits off the trunk and enforcing the PR body format.
- **no-comments** — hands a diff's comments to a fresh reviewer that deletes everything off a short keep list, then fixes the workarounds they excused at the root cause. User-invoked: type `/no-comments`. Adapted from [pstack](https://github.com/cursor/plugins/tree/main/pstack) (MIT).
